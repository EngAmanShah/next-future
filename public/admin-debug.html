🔧 Admin Debug Tool

Purpose: This tool checks and fixes admin access for your Firebase user.

Step 1: Check Current Status

Step 2: Set Admin Claims

Step 3: Verify & Login

After clicking "Set Admin Claims":
1. Wait for success message
2. Click "Check Admin Status" again to verify
3. Sign out completely from your account
4. Close ALL browser windows
5. Wait 10 seconds
6. Open browser and go to login page
7. Sign in again
